# Эксплуатация

## Установка с нуля

1. Python 3.14, Git, 7-Zip, Claude Code (вход в аккаунт с подпиской: `claude` → `/login`).
2. Код: `git clone https://github.com/shibanalex/Ubermensch_Project.git`, затем
   ```
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
3. `.env` по образцу `.env.example` (токен бота, chat_id, ключи Telegram API, Gmail, пароль бэкапов).
4. Данные: восстановить из бэкапа (см. ниже) или начать с пустой папки `D:\Ubermensch`.
5. Вход в Telegram: `telegram_login.bat`.
6. Запуск: `start.bat`; автозапуск: `powershell -ExecutionPolicy Bypass -File scripts\install_autostart.ps1`.

### Дополнительно (рекомендуется)

- **Claude Code отдельно**: `irm https://claude.ai/install.ps1 | iex`, затем `claude` → `/login`. Ядро ищет программу так: `CLAUDE_BIN` → PATH → `%USERPROFILE%\.local\bin\claude.exe` → встроенная в расширение VS Code.
- **Everything** (voidtools) + `es.exe` в `D:\Ubermensch\bin\` — мгновенный поиск файлов. Everything должен быть запущен (Tools → Options → «Start Everything on system startup»). Без него поиск идёт медленным обходом папок.
- **KeePassXC** — хранить `BACKUP_PASSWORD` и ключи.

### Подключение Google Календаря (один раз)

1. console.cloud.google.com → создать проект (любое имя, например «Oswald»).
2. «APIs & Services» → «Library» → **Google Calendar API** → Enable.
3. «OAuth consent screen» → External → заполнить имя и свою почту → в «Test users» добавить свой Gmail.
4. «Credentials» → «Create credentials» → **OAuth client ID** → тип **Desktop app** → Download JSON.
5. Сохранить файл как `D:\Ubermensch\secrets\google_oauth_client.json`.
6. Запустить `google_login.bat` → в браузере разрешить доступ к событиям календаря.

Доступ ограничен событиями календаря; отозвать — myaccount.google.com/permissions.

## Запуск и остановка

| Что | Как |
|---|---|
| Всё (без консоли) | `start.bat` — повторный запуск безопасен, второй экземпляр не стартует |
| Ядро с логами в консоли | `run.bat` |
| Автозапуск | задачи Планировщика «Ubermensch» и «Ubermensch Desktop»; удалить: `Unregister-ScheduledTask -TaskName "Ubermensch*" -Confirm:$false` |
| Остановить | ПКМ по маскоту → «Выход» (закрывает и маскота, и лист); ядро — завершить процесс `pythonw … -m ubermensch` |

### Что понимает папка импорта

| Что положить | Как разбирается |
|---|---|
| Чат Google AI Studio (файл из Google Drive) | глубоко: целиком, без повторов, в память — только новое; сжатый конспект новых сведений — в Obsidian → «Конспекты». Повторить: `POST /api/import/deep` с `{"name": "<имя файла>"}` |
| PDF, Word (.docx), .txt, .md | целиком, как документ |
| Выгрузка ChatGPT или Claude.ai (`conversations.json` или zip с ним) | твои реплики → «Разговоры с ИИ», разбор по месяцам |
| Архивы Google Takeout (`takeout-*.zip`) | «Мои действия» и история YouTube → по месяцам |

Каждый файл читается один раз; пропущенный (неподдерживаемый) или не разобранный из-за лимита — пробуется снова.

## Состояние и диагностика

- **Telegram `/status`** — сервисы, расследование, известные проблемы.
- **Маскот** — `⚠` в строке состояния, если есть проблема; серый `x x` — нет связи с ядром.
- **API**: `GET /api/health` (проблемы + сервисы), `GET /api/investigation` (сбор и разбор), `POST /api/collect` (собрать сейчас), `POST /api/voice` (пересобрать стиль и голос Освальда). Заголовок `Authorization: Bearer <токен из secrets\api_token>`.
- **Лог**: `D:\Ubermensch\logs\ubermensch.log`.

## Известные ситуации и что делать

| Ситуация | Что видно | Что делает система | Что делать тебе |
|---|---|---|---|
| Лимит подписки Claude | «Упёрся в лимит до 22:00» | бот сразу отвечает этим, разбор ждёт до сброса | ничего; меньше гонять Claude Code в это время |
| Claude разлогинился | «Claude разлогинился…» | не дёргает Claude 5 минут, потом проверяет снова; сообщает со второй неудачи подряд (первая после пробуждения обычно ложная — сеть ещё не поднялась) | терминал → `claude` → `/login` |
| Обновилось расширение VS Code / пропал Claude Code | «Не нахожу Claude Code» | ищет `claude.exe` заново при каждом вызове | установить Claude Code или обновить расширение |
| Завершена сессия Telegram | «Нет входа в Telegram» | сбор Telegram пропускается | `telegram_login.bat` |
| Отозван пароль Gmail | «Gmail не пускает…» | сбор почты пропускается | новый пароль приложения → `GMAIL_PASSWORD` в `.env` |
| D: заблокирован после перезагрузки | сообщение в Telegram «Диск заблокирован» | ядро ждёт и стартует само | открыть D: в Проводнике и ввести пароль BitLocker |
| Ночь, а разбор стоит | в логе нет «Разобрано» с 01:00 до 08:00 | ночью разбор идёт быстро, но только пока ноутбук не спит | на ночь — на зарядку. Крышку от сети можно закрывать: «закрытие крышки от сети → ничего не делать» (`powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0`, вернуть сон — `… LIDACTION 1`, затем `powercfg /setactive SCHEME_CURRENT`). От батареи закрытая крышка усыпляет, как обычно |
| Компьютер уснул | — | бот и сервисы замирают и продолжают после пробуждения; оборванный разбор повторяется до 3 раз | ничего |
| Упало окно маскота или лист задач | пропали на пару секунд | присмотр поднимает упавший процесс (2 → 5 → 15 → 60 с), второй работает | прислать `desktop-stderr.log`, если повторяется |
| Упал фоновый сервис | после 3 падений — «Фоновая служба … падает» | перезапуск с паузой 5 с → 5 мин | прислать лог, если повторяется |
| Мало места на D: (< 5 ГБ) | «На диске осталось …» | предупреждает | освободить место |
| Нет пароля бэкапов / 7-Zip | «Резервные копии не делаются…» | бэкап пропускается | задать `BACKUP_PASSWORD` в `.env` |
| Давно нет копии вне ноутбука | «Подключи внешний диск…» | — | подключить носитель с папкой `OswaldBackup` |
| Действие ждёт подтверждения 10 минут | — | считается отказом | — |
| Календарь не подключён / доступ отозван | Освальд говорит «Календарь не подключён…» | инструменты календаря возвращают ошибку | раздел «Подключение Google Календаря» |
| Everything не запущен | — | поиск файлов медленнее (обход папок) | запустить Everything |

## Резервные копии

- Каждую ночь (или днём, если ночью компьютер был выключен) — архив `oswald-ГГГГ-ММ-ДД_ЧЧ-ММ.7z`: база, стиль переписки, голос Освальда, досье. Шифрование AES-256, имена файлов скрыты. Пароль — `BACKUP_PASSWORD` в `.env`. **Храни пароль отдельно от ноутбука** — без него архив не открыть.
- Копия вне ноутбука: создай в корне флешки или внешнего диска папку `OswaldBackup` — при подключении туда скопируется свежий архив (хранится 14 последних).
- В бэкап **не входят** сессия Telegram и `.env`: при восстановлении их проще пересоздать.

### Восстановление

1. Установка по разделу «Установка с нуля», без запуска.
2. Распаковать архив: `"C:\Program Files\7-Zip\7z.exe" x oswald-....7z -oD:\Ubermensch\restore` (спросит пароль).
3. Положить `ubermensch.db` в `D:\Ubermensch\db\`, `tg_style.md` и `oswald_persona.md` — в `D:\Ubermensch\workspace\`, папку `dossier` — в `D:\Ubermensch\`.
4. `telegram_login.bat`, затем `start.bat`.
