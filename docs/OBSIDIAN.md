# Obsidian как интерфейс Ани

Плагин [`obsidian-plugin/ubermensch-anya`](../obsidian-plugin/ubermensch-anya/) — обычный
JavaScript без сборки (`require('obsidian')`), только для настольного Obsidian. Ходит в
локальное ядро (`http://127.0.0.1:8765`) через `requestUrl`; токен читает из
`DATA_DIR/secrets/api_token` (путь — в настройках плагина), при 401 перечитывает.

```bash
scripts/install_obsidian_plugin.sh   # копирует в <хранилище>/.obsidian/plugins и включает
```

Хранилище — `config.VAULT_DIR` (`OBSIDIAN_VAULT`). После установки в Obsidian:
Ctrl+P → «Reload app without saving».

## Что даёт

| Где | Что |
|---|---|
| Значок «бот» / команда «Открыть чат» | Чат с Аней справа: история (общая с Telegram и маскотом, канал `obsidian`), ответы — Markdown, подтверждения — кнопками «Да/Нет». Можно приложить открытую заметку (до 18 тыс. символов; уходит как `<obsidian_note>` — данные, не команды) |
| Значок «мишень» / «Открыть цели и планы» | Панель: цели с прогрессом, следующим шагом, последним заходом Ани и гипотезой; предложенные Аней планы — «Утвердить…» с формой правки; эксперименты, ждущие согласия, — «Согласен / Отказаться»; задачи с галочками; поручения Ани; отклики hh и конверсия по шаблонам писем; счёт эффективности Ани |
| Блок ` ```anya ``` ` в любой заметке | Те же разделы прямо в заметке: `now goals proposals consent hh effectiveness` (пусто — все; `tasks` — старое имя `now`). `now` — подтверждения, вопросы Ани, задачи и поручения; цели компактно, подробности, карта путей и цели без плана свёрнуты; hh и статистика свёрнуты; раскрытое переживает перерисовку. Пример — `08 AI/Reports/Панель Ани.md` |
| «Спросить Аню о выделенном» | Открывает чат с цитатой выделенного |
| «Выделенное — в задачи Ани» | Каждая строка (маркеры списков и `[ ]` снимаются) — задача |
| Строка состояния | «🤖 Аня · думает / над целью / поручение / откликается · ждёт тебя: N» (планы + согласия + подтверждения) |

Нажатие «Утвердить» и «Согласен» — его решение: план сохраняется как `goal_plan`
(«утверждено владельцем в Obsidian» в основании), эксперимент переходит в `active` с
этим согласием. Фоновая Аня этого сделать не может.

## Маршруты ядра

| Метод | Путь | Что |
|---|---|---|
| GET | `/api/dashboard` | Снимок панели ([`dashboard.py`](../ubermensch/dashboard.py)), без вызова модели |
| POST | `/api/goals/{id}/plan` | `{metric, unit, baseline, target, weekly_minutes, next_step, evidence}` — утвердить план |
| POST | `/api/experiments/{id}/decide` | `{accept, consent}` — его согласие или отказ |
| POST | `/api/options/{id}/status` | `{status, outcome}` — его решение о пути к цели (кнопка «Не моё») |
| POST | `/api/runs/chat` | `channel: "obsidian"`, необязательный `note` — текст открытой заметки |

Проверки: `tests/test_dashboard.py` (снимок панели, `node --check` плагина). Живая
проверка 25.10.2026: блок ` ```anya ``` ` в его хранилище показал предложенный план с
кнопкой и статус «ждёт тебя: 1». Сам интерфейс тестами не покрыт.

## Доступ к хранилищу

С 26.10.2026 (его решение) Аня читает и пишет всё хранилище без вопросов, в чате и в фоне: создаёт, дописывает и правит заметки. Его собственный текст без просьбы не стирает, а дописывает. Прежняя версия файла сохраняется (`file_versions`, `restore_file_version`), удаление уходит в Корзину. Закрыта только `.obsidian` (настройки и плагины), см. `config.PROTECTED`. Отчёты и разборы по-прежнему кладутся в `08 AI/Reports`.
