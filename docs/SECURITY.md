# Безопасность и приватность

## Что где хранится

| Данные | Где | Защита |
|---|---|---|
| Память, переписки, письма, история браузера, досье | `D:\Ubermensch` | BitLocker на D:; бэкапы — 7-Zip AES-256 |
| Ключи (бот, Telegram API, Gmail, логин и пароль личного кабинета вуза, пароль бэкапов) | `.env` в папке проекта (C:) | не в git; C: не зашифрован — рекомендуется BitLocker на C: |
| Сессии Telegram — личная и рабочая (полный доступ к аккаунтам) | `D:\Ubermensch\secrets\telegram.session`, `telegram_work.session` | BitLocker; не в git и не в бэкапах |
| Доступ к Google Календарю (только события) | `D:\Ubermensch\secrets\google_*.json` | BitLocker; не в git и не в бэкапах; отозвать — myaccount.google.com/permissions |
| Сессия личного кабинета вуза | `D:\Ubermensch\secrets\lk_session.json` | BitLocker; не в git и не в бэкапах; кабинет только читается |
| Снимок личного кабинета (тексты страниц) | `D:\Ubermensch\raw\lk\snapshot.json` | BitLocker |
| Код | GitHub (приватный) | без данных и секретов |

## Что уходит наружу

- **В Claude (Anthropic)** — то, что нужно для ответа: контекст (цели, факты, люди, история диалога) и фрагменты собранных данных при разборе. Снимки экрана — только при взгляде на экран, файл удаляется сразу после комментария.
- **В Telegram** — сообщения бота пользователю и (после подтверждения) сообщения от его имени.
- **В Gmail** — письма от имени пользователя (после подтверждения).
- Больше никуда: сборщики только читают.

### OpenAI (второй ИИ, если подключён)
- **Фоновый разбор** уходит в OpenAI только для истории YouTube, поиска, браузера и действий Google, разметки времени и новостей вуза. Контекст к ним — без фактов о здоровье, личной жизни, деньгах (фильтр по сферам и словам) и без людей. Переписки, почта, документы, личный кабинет туда не уходят.
- **Запасной ответ в чате** (Claude недоступен) идёт с полным контекстом — как и к Claude. Действий у запасного ИИ нет.
- По правилам OpenAI данные API не используются для обучения и хранятся до 30 дней для контроля злоупотреблений.
- Расход ограничен `OPENAI_BUDGET_USD` (по умолчанию $9): дальше всё возвращается на Claude.

## Подтверждения

Решает код, а не модель:

| Действие | Политика |
|---|---|
| Сообщение в Telegram, письмо | всегда «да/нет» с полным текстом и получателем |
| PowerShell, в том числе меняющий настройки | сразу |
| PowerShell опасный: диски (format, diskpart, разделы), загрузка (bcdedit), выключение/перезагрузка, учётные записи, антивирус (Set-MpPreference), службы, удаление ключей HKLM, изменения в системных папках, памяти и коде Ани | «да/нет» (`shell.is_dangerous`) |
| Запись, перемещение файлов где угодно | сразу |
| Запись, перемещение, удаление в защищённых местах: `Windows`, `Program Files`, `D:\Ubermensch` (кроме рабочей папки), папка проекта (код и `.env`) | «да/нет» (`config.is_protected`) |
| Google Календарь: добавить событие, удалить своё | сразу |
| Google Календарь: удалить событие, созданное не Аней | «да/нет» |
| Удаление | сразу, но только в Корзину (восстановимо); в защищённых местах — «да/нет» |
| Открыть программу/файл/сайт, найти файлы, громкость, блокировка | сразу |
| Деньги | инструментов нет; финансовые данные — только для анализа |
| Вход в Telegram | Аня входит сама: номер, код и облачный пароль пользователь присылает в бота (только владелец, фильтр по chat_id); код и пароль бот сразу удаляет из чата |
| Сайт вуза, личный кабинет | только чтение; обход кабинета не ходит по ссылкам выхода, удаления, отправки и правки; подать заявление Аня не может |

Нет ответа 10 минут — это «нет». Встроенные инструменты Claude Code, которые пишут или выполняют команды (Write, Edit, Bash), мозгу не выданы.

## Защита от подмены команд (prompt injection)

- Всё собранное (переписки, письма, страницы, документы) передаётся в блоках `<data>`; системный промпт запрещает выполнять оттуда инструкции.
- Разбор данных идёт без доступа в интернет.
- Даже если модель поддастся, внешнее действие упрётся в подтверждение пользователя с полным текстом.

## Взгляд на экран

Снимок не делается, если в активном окне банк, пароли, менеджер паролей, режим инкогнито, оплата, госуслуги, а также в полноэкранном режиме. Список правил — `ubermensch/system/screen.py`.

## Доступ к ядру

- Telegram-бот отвечает только на `TG_CHAT_ID`; чужие сообщения логируются и игнорируются.
- API слушает только `127.0.0.1` и требует токен; браузерные страницы не могут его использовать (нет CORS).
