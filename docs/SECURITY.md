# Безопасность и приватность

## Что где хранится

| Данные | Где | Защита |
|---|---|---|
| Память, переписки, письма, история браузера, досье | `D:\Ubermensch` | BitLocker на D:; бэкапы — 7-Zip AES-256 |
| Ключи (бот, Telegram API, Gmail, пароль бэкапов) | `.env` в папке проекта (C:) | не в git; C: не зашифрован — рекомендуется BitLocker на C: |
| Сессия Telegram (полный доступ к аккаунту) | `D:\Ubermensch\secrets\telegram.session` | BitLocker; не в git и не в бэкапах |
| Доступ к Google Календарю (только события) | `D:\Ubermensch\secrets\google_*.json` | BitLocker; не в git и не в бэкапах; отозвать — myaccount.google.com/permissions |
| Код | GitHub (приватный) | без данных и секретов |

## Что уходит наружу

- **В Claude (Anthropic)** — то, что нужно для ответа: контекст (цели, факты, люди, история диалога) и фрагменты собранных данных при разборе. Снимки экрана — только при взгляде на экран, файл удаляется сразу после комментария.
- **В Telegram** — сообщения бота пользователю и (после подтверждения) сообщения от его имени.
- **В Gmail** — письма от имени пользователя (после подтверждения).
- Больше никуда: сборщики только читают.

## Подтверждения

Решает код, а не модель:

| Действие | Политика |
|---|---|
| Сообщение в Telegram, письмо | всегда «да/нет» с полным текстом и получателем |
| PowerShell, меняющий систему | «да/нет» (команды только на чтение — сразу) |
| Запись файла (текст, Word, Excel) в своих зонах: Obsidian `…\Oswald`, `Документы\Oswald`, рабочая папка | сразу |
| Запись файла вне своих зон, перемещение | «да/нет» |
| Google Календарь: добавить событие, удалить своё | сразу |
| Google Календарь: удалить событие, созданное не Освальдом | «да/нет» |
| Удаление | «да/нет», и только в Корзину |
| Открыть программу/файл/сайт, найти файлы, громкость, блокировка | сразу |
| Деньги | инструментов нет; финансовые данные — только для анализа |

Нет ответа 10 минут — это «нет». Встроенные инструменты Claude Code, которые пишут или выполняют команды (Write, Edit, Bash), мозгу не выданы.

## Защита от подмены команд (prompt injection)

- Всё собранное (переписки, письма, страницы, документы) передаётся в блоках `<data>`; системный промпт запрещает выполнять оттуда инструкции.
- Разбор данных идёт без доступа в интернет.
- Даже если модель поддастся, внешнее действие упрётся в подтверждение пользователя с полным текстом.

## Взгляд на экран

Снимок не делается, если в активном окне банк, пароли, менеджер паролей, режим инкогнито, оплата, госуслуги, а также в полноэкранном режиме. Список правил — `ubermensch/system/screen.py`.

## Доступ к ядру

- Telegram-бот отвечает только на `TG_CHAT_ID`; чужие сообщения логируются и игнорируются.
- API слушает только `127.0.0.1` и требует токен; браузерные страницы не могут его использовать (нет CORS).
