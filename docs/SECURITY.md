# Безопасность и приватность

Документ описывает механизмы текущего приложения и их границы. Приложение работает
с правами Windows-процесса; отдельной изоляции ОС для инструментов нет. Подробности
исполнения — в [AI_RUNTIME](AI_RUNTIME.md), задачи усиления — в
[LIMITATIONS](LIMITATIONS.md).

## Что где хранится

| Данные | Где | Защита |
|---|---|---|
| Память, переписки, письма, история браузера, досье | `D:\Ubermensch` | Доступ ОС; шифрование тома настраивается отдельно; архивы 7-Zip шифруются |
| Ключи (бот, Telegram API, Gmail, ЛК, OpenAI, пароль бэкапов) | `.env` в папке проекта | Файл исключён из git; приложение не шифрует его само |
| Сессии Telegram — личная и рабочая (полный доступ к аккаунтам) | `D:\Ubermensch\secrets\telegram.session`, `telegram_work.session` | Не включены в архив приложения; защищать доступ к каталогу и аккаунтам |
| Доступ к Google Календарю | `D:\Ubermensch\secrets\google_*.json` | OAuth scope событий; токены вне архива; отзыв через настройки аккаунта Google |
| Сессия личного кабинета вуза | `D:\Ubermensch\secrets\lk_session.json` | Адаптер предназначен для чтения; сессия остаётся чувствительным credential |
| Снимок личного кабинета (тексты страниц) | `D:\Ubermensch\raw\lk\snapshot.json` | Локальные личные данные, не включён в архив приложения |
| API-токен | `D:\Ubermensch\secrets\api_token` | Даёт доступ ко всему локальному API, включая инструменты и approvals |
| Заметки и документы | `D:\Aleksey\Aleksey\Аня`, `Documents\Аня` | Отдельные хранилища; их резервирование не покрыто текущим Maintenance |
| Код | Checkout / репозиторий проекта | Перед коммитом проверять отсутствие личных данных, не полагаться только на `.gitignore` |

Код не включает BitLocker и не проверяет фактический статус шифрования диска.
При разблокированном томе процессы с достаточными правами пользователя могут
читать данные. Секреты не должны копироваться в fixtures, issue или документацию.

## Что уходит наружу

- **В Claude (Anthropic)** — контекст (цели, факты, люди, история диалога), фрагменты
  собранных данных и результаты инструментов. При визуальном чтении — снимки экрана.
  Автоматический `now.jpg` удаляется после обработки; ручной `request.jpg` остаётся.
- **В Telegram** — сообщения бота пользователю и (после подтверждения) сообщения от его имени.
- **В Gmail** — письма от имени пользователя (после подтверждения).
- **В Google Calendar** — запросы OAuth/API, в том числе создаваемые события;
  добавление события не требует отдельного approval по текущей политике.
- **Во внешние источники** — запросы к сайту/кабинету вуза, погоде, валютам,
  новостям и другим сервисам, используемым инструментами. Чтение удалённого
  источника тоже передаёт ему сетевой запрос и идентификационные данные сессии.
- **Через PowerShell и открываемые программы** возможны дополнительные сетевые
  действия в пределах прав процесса. Фиксированного сетевого allowlist нет.

### OpenAI (второй ИИ, если подключён)
- **Фоновый разбор** использует OpenAI для истории YouTube, поиска, браузера и
  действий Google, разметки времени и публичных новостей вуза. `_profile_context(private=True)`
  исключает часть сфер/слов и людей. Это эвристический фильтр, не анонимизация:
  личные данные могут оставаться в исходном тексте и URL. Основной анализ переписок,
  почты, документов и личного кабинета направляется в Claude.
- **Запасной ответ в чате** (Claude недоступен) идёт с полным контекстом и результатами
  запрошенных инструментов. OpenAI может вызвать общие инструменты для Windows, файлов,
  переписки, календаря и вуза. Подтверждения сообщений, писем и опасных операций остаются
  в коде ядра и возможностей. Фоновый разбор инструментов не получает.
- Адаптер отправляет `store: false`. Это параметр запроса, а не локальная гарантия
  отсутствия любого хранения у провайдера. Условия обработки и хранения зависят
  от провайдера, аккаунта и его актуальных настроек.
- Перед новым запросом/инструментом проверяется `OPENAI_BUDGET_USD` (по умолчанию $9).
  Учёт накопительный и расчётный; уже отправленные и параллельные запросы могут
  превысить порог. Подробности — в AI_RUNTIME.

## Подтверждения

Решает код, а не модель:

| Действие | Политика |
|---|---|
| Сообщение в Telegram, письмо | всегда «да/нет» с полным текстом и получателем |
| PowerShell, в том числе меняющий настройки | сразу |
| PowerShell опасный: диски (format, diskpart, разделы), загрузка (bcdedit), выключение/перезагрузка, учётные записи, антивирус (Set-MpPreference), службы, удаление ключей HKLM, изменения в системных папках, памяти и коде Ани | «да/нет» (`shell.is_dangerous`) |
| Запись, перемещение вне защищённых мест | сразу |
| Запись, перемещение, удаление в защищённых местах: `Windows`, `Program Files`, `D:\Ubermensch` (кроме рабочей папки), папка проекта (код и `.env`) | «да/нет» (`config.is_protected`) |
| Google Календарь: добавить событие, удалить своё | сразу |
| Google Календарь: удалить событие, созданное не Аней | «да/нет» |
| Удаление | сразу, но только в Корзину (восстановимо); в защищённых местах — «да/нет» |
| Открыть программу/файл/сайт, найти файлы, громкость, блокировка | сразу |
| Деньги | инструментов нет; финансовые данные — только для анализа |
| Вход в Telegram | Номер, код и облачный пароль могут вводиться через бота владельца; код и пароль бот пытается удалить из чата. Локальные login-скрипты — отдельный путь входа |
| Сайт вуза, личный кабинет | только чтение; обход кабинета не ходит по ссылкам выхода, удаления, отправки и правки; подать заявление Аня не может |

Нет ответа 10 минут — это «нет». Встроенные инструменты Claude Code, которые пишут или выполняют команды (Write, Edit, Bash), мозгу не выданы.

Правила в таблице относятся к конкретным адаптерам. `shell.is_dangerous` ищет
опасные признаки эвристически и не анализирует произвольный PowerShell как
изолированную программу. Права процесса остаются доступными команде. Проверки
файловых путей не образуют общего read allowlist: `read_file` может читать
доступные процессу UTF-8 файлы, в том числе чувствительные. Ограничение чтения
секретов в описании инструмента — инструкция модели, не запрет ОС.

Своё событие календаря распознаётся по редактируемому маркеру description.
Фильтр ссылок личного кабинета также эвристический. Эти механизмы нельзя считать
защищёнными идентификаторами владения или формальным доказательством отсутствия
любого побочного эффекта.

Общий API инструментов доступен только с токеном ядра. Токен даёт доступ к системным
возможностям; он не передаётся модели. Аргументы проверяются по схеме, неизвестные
инструменты и дополнительные параметры отклоняются до выполнения.
При переключении ИИ нельзя автоматически повторять уже начатые действия. Журнал попытки
хранит только имя и статус инструмента; сообщения, содержимое файлов и секреты в него
не записываются. После ошибки с неопределённым результатом цикл останавливается.

Это не exactly-once: повторный прямой HTTP-вызов с тем же run_id снова выполнит
инструмент. После рестарта approval-Future утрачен; старую pending-запись нельзя
использовать как сохранённое продолжение. Нет отдельных прав «только чтение»
и «может подтверждать» для разных держателей токена.

## Защита от подмены команд (prompt injection)

- Всё собранное (переписки, письма, страницы, документы) передаётся в блоках `<data>`; системный промпт запрещает выполнять оттуда инструкции.
- Фоновому разбору не выдаются инструменты браузера и ОС; сам вызов облачной модели
  использует сеть и передаёт ей текст.
- Сообщения и письма проверяются через approval с полным текстом. Для других
  инструментов действуют их собственные правила; не всякое внешнее действие
  требует подтверждения.
- Разметка `<data>` и системные инструкции помогают отделить источник от команды,
  но не гарантируют устойчивость модели к prompt injection. Граница исполнения
  должна проверяться в коде независимо от формулировок модели.

## Взгляд на экран

Снимок не делается, если в активном окне банк, пароли, менеджер паролей, режим инкогнито, оплата, госуслуги, а также в полноэкранном режиме. Список правил — `ubermensch/system/screen.py`.

Проверка основана на приложении и заголовке активного окна. Она не распознаёт
весь чувствительный текст на экране и не закрывает содержимое других видимых окон.
Автоматический observer удаляет `screens/now.jpg` в finally после обработки;
инструмент screenshot сохраняет `screens/request.jpg` и не удаляет его автоматически.
OpenAI получает от этого инструмента путь, без автоматической передачи изображения.

## Доступ к ядру

- Telegram-бот отвечает только на `TG_CHAT_ID`; чужие сообщения логируются и игнорируются.
- API слушает только `127.0.0.1` и требует bearer-токен. Отсутствие CORS ограничивает
  обычные межсайтовые запросы браузера с таким заголовком, но не заменяет аутентификацию
  и не защищает от локальной программы, которая получила токен.
- Ротация токена требует согласованного обновления файла и ядра: сервер хранит
  ожидаемое значение с момента старта. Клиенты перечитывают файл, но уже открытые
  SSE-соединения отдельно не переавторизуются.
- Удалённый доступ, pairing устройств, отзыв отдельного клиента и scope прав пока
  не реализованы. Направление развития — в [EVOLUTION](EVOLUTION.md).
