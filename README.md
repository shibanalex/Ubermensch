# Übermensch

Личная AI-система, которая помогает своему владельцу добиваться целей. Её лицо — **Аня (anya.exe)**:

- маскот-консоль с мордочкой `:3` на рабочем столе — клик, вопрос, ответ пузырём;
- бумажный лист задач, приклеенный к рабочему столу;
- бот в Telegram, который пишет «как человек» и в стиле владельца;
- агент, который действует на компьютере и от имени владельца: сообщения и письма отправляет после подтверждения; для файлов, Windows и календаря действуют отдельные [политики](docs/SECURITY.md);
- расследователь: собирает переписки, почту, браузер, документы, активность — и составляет досье;
- и всё это помнит: факты, людей, цели, задачи.

Мозг — Claude через Claude Code на подписке. Данные — локально, на зашифрованном диске D:.
Основная база, импорты и служебные данные — в `D:\Ubermensch`; заметки Ани — в существующем
хранилище Obsidian `D:\Aleksey\Aleksey\Аня`. Пути можно переопределить в настройках.
Если Claude недоступен, подключённый OpenAI продолжает разговор с общими инструментами
для Windows, файлов, Telegram, почты, календаря и вуза. Подтверждения выполняются ядром
независимо от выбранного ИИ.

## Быстрый старт

Для нового checkout, в PowerShell из корня проекта. Настройки и зависимости:
[CONFIGURATION.md](docs/CONFIGURATION.md). Полный запуск включает сбор данных;
для знакомства разработчика сначала доступны [изолированные тесты](docs/TESTING.md).

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item -LiteralPath .env.example -Destination .env
# Заполнить новый .env; существующий файл настроек не перезаписывать.
New-Item -ItemType Directory -Path 'D:\Ubermensch\db' -Force | Out-Null
# Если UBERMENSCH_DATA изменён, создать db внутри выбранного каталога.
.\telegram_login.bat
.\start.bat
```
